# 广州校园实景与地图物件对照

0.5.1 采用建成后的校园照片校对建筑、铺装和室内家具。下列链接指向摄影作品或原作者的报告。游戏使用原地图几何与重新绘制的像素材质。照片用于辨认外观，建筑轮廓、楼层、孔洞、出入口与通行位置采用地图包的坐标。
