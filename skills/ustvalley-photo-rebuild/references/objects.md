# 物品与装饰的渐进重建

## 先放进场景，再逐渐校正

照片重建包括建筑、家具、设施、物品和装饰。用户的优先级是“物品在那里，而且能识别”，不要求第一次摆放精确。辨认出物品及大致区域后，默认先制作并放置可识别的像素版本；距离、角度、数量局部遮挡和尺寸不完全确定，不应自动变成 needs-evidence。

每张照片先盘点可辨认的对象：桌椅与长凳、柜架、花盆与绿植、灯具、垃圾桶、饮水机、固定标识与展示板、雕塑、墙饰和其他有辨识度的陈设。按“大件与区域特征 → 常见小物 → 细部装饰”的顺序处理，尽量覆盖；不要只检查外墙后就结束任务。仍可独立完成的对象不因另一物件不清楚而搁置。

能移动的桌椅、盆栽、展示板也可以先按照片所示布置放入场景，不必证明永久固定。记录照片时间已知或未知，作为可调整的场景陈设。行人和偶然路过的车辆默认不固化；用户另有要求时按其要求处理。

## 可识别的像素表达

优先保留轮廓、主要颜色、材质分区和辨识部件，例如长椅的靠背与椅脚、花盆的盆口与叶簇、垃圾桶的开口、灯具的灯罩和杆。照片不清楚的小字用概括形状表达，不编造标语、个人信息或精确尺寸。

沿用现有几何构件和像素材质；室外需在环视时仍有体积，避免仅放一块始终面对镜头的贴片。壁画、海报和地面标线可以作为依附表面的像素装饰。不得直接把私有原图裁切当成公开纹理。

## 合理的近似落位

- 先确定所属场景和大致区域，参考墙边、走廊、房间、绿地或现有家具的相对关系选择合理位置。没有精确深度时先近似放置，不从单张照片宣称测量结果。
- 尺寸可以参考常见物品和角色比例估计；不要把透视中的像素长度直接当世界尺寸。
- 地面物品落地，壁饰贴墙，吊灯依附天花板或悬挂支点，桌上摆件依附桌面。近似不等于悬浮或穿透。
- 立体实物按用途同步局部碰撞与遮挡；贴画、地毯等不应产生多余阻挡。宁可稍移到通道边缘，也不要堵门、堵楼梯或堵住已有路线。
- 只在对象本身无法辨认、连大致场景都无法确定，或无法在不改建筑结构的情况下安全放置时，记录 deferred 及具体原因。位置不够精确本身不构成搁置理由。

## 稳定身份与后续照片

给每个物理实例一个稳定 objectId，例如 academic-f2-planter-01；不同照片指向同一个花盆时使用同一 ID。不要因拍摄角度、照片ID或新坐标变化而创建重复物件。先查当前场景的生成配置及历史报告，再决定新增还是更新；同类资产可共享模型，实例位置分别保留。

新增对象没有源地图 featureId 是正常情况，不要编造 sourceId。把 objectId、模型或构件参数、位置与朝向保存在实际参与地图生成的项目配置或模块中，并在 review.json.objects 中记录依据。review.json 是报告，不是地图运行时；仅填写报告不算已放入地图。

更多照片到来时，优先更新同一实例的位置、比例、颜色和细节。近似记录保持 approximate，只有有明确证据时才改为 confirmed；两者都能作为 applied 的有效结果，不以达到精确位置为验收前提。一张新照片没有拍到物品，不代表物品已经移走。

验收重点：物品可识别、在合理区域、比例协调、依附关系正确、没有重复与堵路。截图同时展示整体布置和物件近景。
